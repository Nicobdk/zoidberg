# 📚 Documentation Centrale du Projet ZOIDBERG

Bienvenue dans l'espace documentaire. Pour garder le répertoire principal propre, toutes les documentations spécifiques ont été rangées ici par catégorie.

## 📁 Structure du dossier

### [1_Onboarding](./1_Onboarding/)
Contient tout ce qu'il faut pour comprendre comment installer et démarrer le projet.
- `QUICKSTART.md` : Guide de démarrage rapide.
- `SETUP.md` : Installation détaillée de l'environnement Python.
- `GIT_MULTI_REMOTES.md` : Guide pour gérer les dépôts Git (groupe vs perso).

### [2_Architecture_et_Recherche](./2_Architecture_et_Recherche/)
La documentation technique du code et de l'intelligence artificielle.
- `ARCHITECTURE.md` : Explication des scripts et de l'arborescence.
- `PARCOURS_COMPLET_MODELES.md` : Historique des modèles (de l'échec aux réussites).
- `PROJECT_EXPLANATION.md` : Explications vulgarisées du contexte médical.

### [3_Presentation_et_Livrables](./3_Presentation_et_Livrables/)
Tout ce qui concerne la validation du projet et l'oral final.
- `PLAN_PRESENTATION_ORAL.md` : Script pour la présentation orale.
- `GUIDE_PEDAGOGIQUE_COMPLET.md` : Explication vulgarisée pour les professeurs.
- `VALIDATION_CRITERES.md` : Vérification des exigences du jury.
- `FINAL_DELIVERABLES.md` : Checklist des rendus.

### [4_Meta_Gestion_IA](./4_Meta_Gestion_IA/)
Fichiers utilisés pour le pilotage du projet avec l'IA.
- `BRIEFING_LLM_PROJET.md` : Prompt master pour les intelligences artificielles.
- `PLAN_RESTRUCTURATION_PROJET.md` : Plan de refactorisation.
